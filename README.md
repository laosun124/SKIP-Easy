# SKIP 易用版 · 3.1.8

基于 [GuoXiCheng/SKIP](https://github.com/GuoXiCheng/SKIP) 开发的第三方修改版，通过 Android 无障碍服务尝试点击开屏广告的跳过按钮。修复了一些使用问题，并精简界面，让初次使用更容易上手。

感谢 GuoXiCheng 及原项目贡献者。本项目保留原项目的历史、[GPL-3.0 许可证](LICENSE) 和 [免责声明](DISCLAIMER.md)，不代表原作者的官方发行版本。

## 下载与使用

从 [最新版发布页](https://github.com/laosun124/SKIP-Easy/releases/latest) 下载 APK。Android 8.0 及以上可安装；与此前同签名版本可以覆盖安装并保留设置。

1. 打开 SKIP，按提示开启无障碍服务。
2. 进入「应用保活」，选择手机系统，按步骤设置后台运行权限。
3. 按需设置「应用白名单」，或执行一次自动识别后再手动调整。
4. 普通应用每次进入前台后，SKIP 仅在前 6 秒尝试跳过开屏广告。

## 微信小程序

白名单页面提供 **微信小程序专属优化** 开关，默认开启并保存选择。

- **开启**：微信普通页面不自动点击；仅对确认的小程序广告栏尝试点击左上角「跳过」。微信在白名单中也可使用专用规则。
- **关闭**：微信本体和小程序都不自动点击。

每条小程序广告从识别时起最多尝试 6 秒。位置按实际窗口与控件计算，不固定为某张截图的坐标或屏幕比例。规则不保证覆盖所有手机、微信版本或广告形式。详见 [微信优化说明](WECHAT_OPTIMIZATION.md)。

## 其他功能

- 按新获取的控件识别并重试点击，减少过早点击未响应的问题。
- 白名单支持搜索、显示系统应用和一次性自动识别；批量识别会覆盖已有应用的手动选择，完成后仍可调整，不会改变微信专属开关。
- 识别支持 com.android. 前缀、常见国外厂商前缀和具体应用名单；无法完整判断应用国别，可手动修正。
- 支持隐藏最近任务卡片、常驻通知和按手机系统展示保活步骤。
- 功能介绍内置离线阅读，界面支持浅色、深色及底部导航栏配色。
- 移除严格模式、布局检查、自定义配置编辑及原版 APK 自动更新入口；更新本版请手动下载新的安装包。

## 验证与限制

66 项单元测试覆盖前台时间窗、点击重试、白名单识别、微信广告栏几何匹配、微信专属开关与时间限制等。测试不等于所有品牌手机上的实际验证，也不保证所有广告均能跳过。

发布 APK 沿用此前版本的签名以支持覆盖安装，私钥不在仓库中。其他签名的原版或自行构建的安装包可能无法直接覆盖。

## 从源码构建

使用 JDK 17 和 Android SDK 34，在 Android Studio 中打开项目，或运行：

```bash
sh gradlew :app:testReleaseUnitTest :app:assembleRelease
```

APK 输出到 app/build/outputs/apk/release/。构建配置使用构建者本机的调试密钥签署非调试 Release 包，因此自行构建的签名通常与此处发布的 APK 不同。
