# SKIP 易用版 3.1.8

基于 [GuoXiCheng/SKIP](https://github.com/GuoXiCheng/SKIP) 开发的第三方修改版，通过安卓无障碍服务尝试点击开屏广告的跳过按钮，修复使用问题并简化操作。

普通应用每次进入前台后的前 6 秒生效。微信使用独立的「微信小程序专属优化」开关，普通页面不使用通用关键词规则，小程序广告从识别时起最多尝试 6 秒。

应用提供白名单、一次性自动识别、按系统展示的保活指引、隐藏最近任务卡片和离线功能介绍。跳过效果取决于应用页面，不能保证覆盖所有广告。
